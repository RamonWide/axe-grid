# Code of Conduct

Axe-Grid follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to every project space: issues, pull requests, discussions and any other
place where the project is represented.

## In short

We want this to be a project where a guitarist filing a first bug report and an experienced
programmer are both treated well. So:

- Be kind and patient. Assume good intent, and remember that not everyone is a developer or a
  native English speaker.
- Disagree about ideas, not about people. Critique code and designs, with reasons.
- Accept correction gracefully, and give it gracefully.
- No harassment, insults, sexualised language or imagery, personal attacks, or publishing someone's
  private information.

## Reporting

If someone's behaviour is a problem, report it to the maintainers privately: use the **Report
content** option GitHub shows on the comment or issue, or contact the repository owner through the
contact details on their GitHub profile. Reports are handled confidentially.

Maintainers may remove, edit or reject comments, commits, issues and other contributions that
break this code, and may temporarily or permanently ban a contributor for behaviour they judge
inappropriate, following the enforcement guidelines of the Contributor Covenant.
