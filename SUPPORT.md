# Getting help

- **Installing and first steps:** [docs/install.md](docs/install.md), including a troubleshooting table.
- **Questions and ideas:** [Discussions](https://github.com/RamonWide/axe-grid/discussions).
- **Something is broken:** [open an issue](https://github.com/RamonWide/axe-grid/issues/new/choose).
  Say which Axe-Fx II model and firmware you have, your operating system, and how the unit is connected.
- **Security problems:** see [SECURITY.md](SECURITY.md); please do not use public issues.

Axe-Grid is a volunteer project and is not connected to Fractal Audio Systems. For help with the
unit itself, its firmware or the original editor, use Fractal Audio's own support.
